# HDCマイクラ部 活動記録サイト

<https://hdc-lyu.github.io/hdc-mine-club/>

Jekyll + GitHub Pages で運用しています。
`main` ブランチにpushすると GitHub Actions が自動でビルド・公開します。

## ローカルで確認する

```bash
bundle exec jekyll serve
```

## 保守手順

記事の追加、部員の追加、配色の変更などの手順は保守情報ページにまとめています。

<https://hdc-lyu.github.io/hdc-mine-club/admin/>（ソース: `admin.markdown`）
